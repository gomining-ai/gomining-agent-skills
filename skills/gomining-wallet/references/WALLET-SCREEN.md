# Wallet Screen Layout (mobile app)

What a user sees on the **Wallet** screen in the mobile app. Use this to tell users where a control lives. Account-specific values (balances) are not listed here — only the fixed layout.

The Wallet is one of the five tabs in the bottom tab bar, and is also reachable from the ☰ drawer under **ACCOUNTS**.

| Element | What it is |
|---------|------------|
| **Total balance** | Combined balance; the eye icon hides/shows it (hidden renders as `******`) |
| Refresh icon | Top-right, refreshes balances |
| **Create card ›** banner | Opens the GoMining Card creation flow |
| **Top up** | Deposit funds |
| **Convert** | Exchange one asset for another (no "more" menu on mobile) |
| **Instant Funds** | Access USDT/USDC by locking BTC or a miner as collateral (no sale) |
| **Withdraw** | Withdraw funds |
| **Simple earn** row | Shows "Next payout in hh:mm:ss" and opens the Simple earn screen |
| **Crypto** list | One row per asset: icon, ticker, current price with 24h direction arrow, balance and its USD value |

Assets that can be placed in Simple Earn additionally show an **APR** badge next to the ticker in the Crypto list.
