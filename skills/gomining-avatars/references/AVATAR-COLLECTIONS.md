# Avatar Collections Reference

## Overview

GoMining avatars are functional avatars assigned to Digital Miners. Each race has a unique ability that activates when the avatar is set as your profile picture; only one ability can be active at a time. There will be 10 series in total.

## Race Details

### 1. Humans — Automated Service

| Attribute | Detail |
|-----------|--------|
| Release date | January 23, 2024 |
| Unique Ability | **Automated Service** — applies the 3% maintenance discount automatically, with no need to manually click the Service button |
| Affects | Mining farm maintenance cost |
| Tradeable | Yes |

### 2. Sentinels — 20% Discount on Spells

| Attribute | Detail |
|-----------|--------|
| Release date | April 10, 2024 |
| Unique Ability | **20% Discount on Spells** — every spell and boost in Miner Wars is 20% cheaper |
| Affects | All spells and boosts in Miner Wars (no effect outside Miner Wars) |
| Tradeable | Yes |

### 3. Cryptiles — Enhanced Efficiency

| Attribute | Detail |
|-----------|--------|
| Release date | September 19, 2024 |
| Unique Ability | **Enhanced Efficiency** — reduces miners' energy consumption by 1 W/TH |
| Affects | Farm-wide energy efficiency; value cannot go below 20 W/TH |
| Tradeable | Yes |

### 4. Luminars — +1 VIP Level

| Attribute | Detail |
|-----------|--------|
| Release date | October 16, 2025 |
| Unique Ability | **+1 VIP Level** — raises VIP level by 1, without meeting the standard requirements |
| Eligibility | No TH requirement; active only while set as profile picture |
| Tradeable | Yes |

### 5. Magmars — Blazing Multiplier (×1.4)

| Attribute | Detail |
|-----------|--------|
| Release date | May 18, 2026 |
| Unique Ability | **Blazing Multiplier** — applies a ×1.4 multiplier to base Simple Earn yield (equivalent to Legend 3 / VIP level 18) |
| Affects | Simple Earn yield only; no stacking — if your VIP multiplier exceeds ×1.4, the higher value is used |
| Limitations | No effect where Simple Earn is unavailable (e.g., the United States) |
| Tradeable | Yes |

## Luminar VIP Boost Rules

| Rule | Detail |
|------|--------|
| Boost | +1 VIP level immediately when set as profile picture |
| Requirement | None — works without meeting the standard VIP requirements; the only condition is that the avatar is set as profile picture |
| Removal | VIP level reverts when avatar is removed |
| GoBox | Issued once for the new VIP level |
| Re-assignment | GoBox is NOT re-issued on reassignment |
| Bronze GoBox | NOT issued (anti-farming protection) |

## Assignment Rules

- Each miner can have one avatar assigned at a time.
- Avatars can be reassigned between miners.
- Trading an avatar on the marketplace removes it from the miner it was assigned to.
- Luminar VIP boost only applies while the avatar is actively assigned.
