# Marketplace Reference

## Overview

The GoMining secondary marketplace allows users to buy, sell, and trade Digital Miners and avatars in a peer-to-peer environment.

## Tradeable Assets

| Asset Type | Description | Tradeable |
|-----------|-------------|-----------|
| **Digital Miners** | Miners representing data center computing power | Yes |
| **Human Avatars** | Cosmetic avatars from Humans collection | Yes |
| **Sentinel Avatars** | Cosmetic avatars from Sentinels collection | Yes |
| **Cryptile Avatars** | Cosmetic avatars from Cryptiles collection | Yes |
| **Luminar Avatars** | Premium avatars with VIP boost capability | Yes |

## Marketplace Features

| Feature | Description |
|---------|-------------|
| **Listing** | Users set their own asking price |
| **Buying** | Browse and purchase listed assets |
| **Settlement** | On-chain transaction settlement |
| **Search** | Filter by type, hashrate, price, and attributes |
| **History** | Transaction history for each asset |

## Trading Digital Miners

| Consideration | Detail |
|--------------|--------|
| Hashrate Transfer | Hashrate transfers with the miner NFT to the new owner |
| Mining Rewards | Pending rewards are settled before transfer |
| Maintenance | New owner assumes maintenance responsibility |
| Assigned Avatar | Avatar is unassigned upon miner sale |

## Trading Avatars

| Consideration | Detail |
|--------------|--------|
| Assignment | Avatar is removed from miner upon sale |
| Luminar Boost | VIP boost is removed from seller and available to buyer |
| GoBox | Previous GoBox issuance history is tied to the user, not the avatar |

## Merchandise

GoMining offers physical branded merchandise through the Marketplace **Merch** area.

| Category | Details |
|----------|---------|
| Type | Physical branded products |
| Branding | Official GoMining branding |
| Purchase | Available through the Marketplace interface |
| Shipping | Region-specific shipping details provided at checkout |

## Rotating "Claim now" merch drops

The Marketplace Merch area also surfaces **rotating drops** — a featured item with a **"Claim now"** call-to-action. The specific item on offer **changes over time** (previous examples included a "time piece"; as of **2026-08-26** the current drop is **Epic X GoMining**). Because the drop rotates, treat each one as a snapshot — don't hardcode past items as the current answer, and don't rely on memory for eligibility or claim mechanics.

**Eligibility, requirements, and claim mechanics live behind the "Claim now" button in the app.** They are not documented in this skill and can differ per drop. When a user asks "why is there a [item] I can claim?", "how do I claim it?", "who is eligible?", or "what does it cost?":

1. Confirm the Merch **"Claim now"** rotating drop feature exists — it's not a scam or a bug.
2. Say the specific rules/eligibility/cost for the current drop are shown **after tapping "Claim now"** in the app, not in the general help docs.
3. Do **not** invent drop-specific eligibility criteria (VIP tier thresholds, TH requirements, referral status, prices) from memory — every drop has its own terms, and the assistant does not have a tool to look them up.
4. If the user has already opened the Claim now flow and is confused by a specific rule shown there, collect the details in text and contact GoMining support.

Do **not** confirm or deny that a drop is free — some drops may require a payment or a specific qualification, so "free claim" is not a safe default. The app screen is the source of truth.
