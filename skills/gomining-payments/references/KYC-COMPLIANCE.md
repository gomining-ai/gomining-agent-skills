# KYC / Compliance Reference

## Overview

GoMining requires identity verification (KYC) to access certain platform features. There are two verification levels with different requirements and access permissions.

## Verification Levels

### KYC Basic - Proof of Identity (POI)

| Requirement | Description |
|-------------|-------------|
| ID Document | Valid government-issued identity document (passport, national ID) |
| Selfie | Live selfie for facial recognition / liveness check |
| Questionnaire | Basic user information questionnaire |

**Services Unlocked with KYC Basic:**

| Service | Access |
|---------|--------|
| Withdrawals | Enabled |
| Miner Minting | Enabled |
| Marketplace | Enabled |
| Visa Card | Not available (requires KYC Advanced) |

### KYC Advanced - Enhanced Due Diligence (EDD)

| Requirement | Description |
|-------------|-------------|
| Tax Information | Tax residency country and tax identification number |
| Employment Details | Current employment status, employer, and role |
| Proof of Address | Utility bill, bank statement, or government document (recent) |
| Phone Verification | Verified phone number linked to account |

**Services Unlocked with KYC Advanced:**

| Service | Access |
|---------|--------|
| All KYC Basic services | Enabled |
| GoMining Visa Card | Enabled |

## Compliance Notes

| Topic | Detail |
|-------|--------|
| Regulation | International AML/KYC standards |
| Document Validity | Documents must be valid and not expired |
| Language | Documents in Latin script or with certified translation |
| Processing Time | Typically minutes for automated checks |

## Common Rejection Reasons

| Reason | Resolution |
|--------|-----------|
| Blurry document photo | Retake photo in good lighting |
| Expired document | Use a valid, non-expired document |
| Selfie mismatch | Ensure face matches ID document |
| Incomplete questionnaire | Fill all required fields |
| Unsupported document type | Use passport or national ID |
| Restricted territory | Service unavailable in blocked countries |
