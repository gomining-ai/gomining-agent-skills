# VIP Levels — Thresholds and Qualification Paths

## Three qualification paths

The **VIP status** screen states the rule directly: under **"Next level: <level>"** it says **"Reach it by any one of these"** and then lists three requirements side by side:

| Path | Unit shown on screen |
|------|----------------------|
| **Power** | TH (e.g. "99.9 / 100 TH") |
| **Votes** | veGOMINING (e.g. "45.7 / 1K veGOMINING") |
| **Referral activity** | USD (e.g. "$0 / $10K") |

Each path shows progress toward the next level, and the one the user is nearest to is marked **"You're closest here"**. The Power card has a **Get power** button; the Votes and Referral activity cards have **+** buttons.

Any single path is enough — the user does not need to satisfy all three.

The Help Center states the same rule from the referral side: *"Referral activity is a way to increase your VIP level, in addition to mining power (TH) and veGOMINING votes."* It reflects the referrals' **last 180 days** and updates once a day — for what counts toward it, see [Referral FAQ](../../gomining-promos/references/FAQ-REFERRAL.md).

## VIP status screen layout

Reached from **Profile → VIP level** card. The screen shows:

- **Current level** with the level badge, and an **All VIP levels** button.
- Three benefit cards for the current level: **Maintenance discount**, **Referral mining royalty**, **Simple Earn multiplier**.
- **Next level** block with the three qualification paths described above.
- A **Platinum+** badge (links to the subscription).
- **VIP Raffles & Contests ›**.
