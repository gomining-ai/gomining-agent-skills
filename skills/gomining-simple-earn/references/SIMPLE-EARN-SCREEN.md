# Simple Earn Screen Layout

What a user sees on the **Simple earn** screen. Use this to point users at a control or a figure. Account-specific values (balances, earned amounts) are not listed here — only the fixed layout.

Reached from the **Wallet** screen (a **Simple earn** row showing a "Next payout in hh:mm:ss" countdown) or from the **Simple earn** card on the app Home screen.

## Header

| Element | What it is |
|---------|------------|
| **Total rewards** | Cumulative rewards, in USD with the BTC equivalent below |
| Eye icon | Hides/shows every amount on the screen — when off, figures render as `******` |
| Chart | Rewards accrual over time |
| **?** icon | Opens Simple Earn help |

## Stats panel

| Element | What it is |
|---------|------------|
| **APR multiplier** | The VIP multiplier applied to the base APR, shown as a badge (e.g. x1.2) |
| **Yesterday** | Rewards credited the previous day |
| **Last 30 days** | Rewards over the last 30 days |
| **Next reward** | Countdown to the next payout |

## Actions

Three round buttons: **Buy crypto**, **Deposit**, **History**.

## Earning now

A list of the assets currently earning. Each row shows the asset, its **APR** as a badge, its current unit price, the deposited amount and its USD value.
