# App Navigation — Section Paths

Use these section names when directing users to specific parts of the GoMining app. The system automatically converts section names into navigation links.

<!-- Structure enriched from ЛК screenshots (web app footer sitemap + top-nav "..." menu), 2026-07 -->

## Top navigation

The web app's top bar shows: **My miners**, **Marketplace**, **GOMINING**, **Governance**, and a **"..."** (more) menu. The "..." menu contains: **Launchpad**, **Leaderboards**, **Miner Wars**, and **Academy**. The top-right holds the wallet balance, notifications, rewards/GoBox, and profile.

## Mobile app navigation (iOS / Android)

<!-- Structure from iOS app screenshots, 2026-07 -->

On the **mobile app**, the same sections live behind the **menu button (☰) in the top-left** of the Home screen, which opens a side navigation drawer. Scrolled top to bottom, the drawer is grouped like this:

| Group | Items |
|-------|-------|
| **MY MINERS** | Mining farm, Dashboard, Rewards |
| **MARKETPLACE** | Miners, GoMiners, Travel, Merch, My listings |
| **GOMINING** | Buy, Liquidity |
| **ACCOUNTS** | Wallet, Cards, Instant Funds |
| **GAME** | Miner Wars |
| **GOVERNANCE** | Tokenomics, My lock, Voting |
| **LAUNCHPAD** | Launchpad |
| **LEADERBOARDS** | Miner rewards, Miner uniqueness, Farms, Liquidity |
| **REFERRAL PROGRAM** | Referral program |
| **LEARN** | Academy |
| **SUPPORT** | Info, Support, Rate app |

A language toggle and a Light/Dark theme switch are pinned at the bottom of the drawer, below the scrolling list.

The Home screen itself shows the wallet balance with a **Main** account dropdown and an eye icon that hides/shows the amount, a row of four quick-action buttons, a BTC / GOMINING price row, and status cards (Simple earn, Mining, VIP progress, Platinum+, Hashback). An **Assistant** bar sits above the tab bar.

**Bottom tab bar.** The mobile app has a five-icon tab bar on every main screen, left to right: **Home**, **Marketplace**, **My miners**, **Wallet**, **Profile**.

**To find the GOMINING token section / buy GOMINING tokens on mobile (iOS or Android):** tap the **☰ menu** (top-left) → scroll to the **GOMINING** group → **Buy**. This is the mobile equivalent of the web **GOMINING → Buy** path. When a user asks where the GOMINING token section is on iOS, give this path directly rather than saying you lack iOS navigation details.
