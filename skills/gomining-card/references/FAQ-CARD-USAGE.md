# GoMining Card — Where and How to Use

## Where the Card Works

The GoMining Card works wherever **Visa cards** are accepted:

- **Physical stores:** retail locations, supermarkets, and other outlets that accept Visa.
- **Online stores:** one-time purchases on e-commerce sites.
- **ATMs:** cash withdrawals from ATMs that accept Visa (see below).

## Unsupported Functions

| Feature | Supported? |
|---------|-----------|
| Recurring/subscription payments (streaming, auto-renewals) | No |
| Bank transfers via IBAN | No |
| External deposits from other cards or bank accounts | No |
| Card-to-card transfers (top-up via card number) | No |
| Balance inquiries at ATMs | No — ATMs always show €0; check balance in the GoMining app |
| **Exporting card transaction history (CSV / PDF)** | **No** — no export button in the card section; escalate for tax/accounting requests |

## Card transaction history — no export

**There is no built-in export for GoMining Card transaction history.** Card purchases and top-ups can be viewed inside the app (Card section → transaction list), but there is **no CSV / PDF / XLSX download** available for the user to pull that data out. Don't tell users to look for an "Export" / "Download" / "Statement" button in the card section — it doesn't exist.

If a user asks for card transaction data — commonly for **tax reporting**, **expense accounting**, or personal records — do **not** promise an export path that isn't there and don't invent a workaround. contact GoMining support so support can arrange the data or advise. In the meantime, the user can view (but not export) each transaction row in-app.

This is the same gap as **Wallet transaction history** — no Wallet export either. Only **Mining rewards** have a documented CSV export (Rewards → Export CSV, emailed, max 365 days). Do not conflate the three products: rewards CSV export exists; card export doesn't; wallet export doesn't.

## ATM Cash Withdrawal

You can withdraw cash from ATMs using your **virtual card** via Apple Pay or Google Wallet:

1. Link your card to Google Pay or Apple Pay.
2. Find an ATM with contactless (NFC) support.
3. Tap your phone against the NFC reader.
4. Enter your PIN.
5. Request the withdrawal.

ATM limits: up to €1,000/day and €5,000/month.

## Card Currency Conversion

When you make a purchase, the selected crypto is instantly converted into:
- **EUR** for EEA+ country users
- **USD** for other eligible countries

The card's billing/display currency is **determined by your region**, not chosen manually.

### My card funds used to show in USD and now show in EUR — is that normal?

Yes, this is expected. The card's billing/display currency is set by your **region**: **EEA+ users are billed in EUR**, other eligible countries in **USD**. A switch from USD to EUR means your card is now being treated under the EEA+ (EUR) region. Your underlying balance and crypto assets are unchanged — only the fiat currency the card converts to and displays in changes. This is not an error and does not affect the value of your holdings.

## Card Order Status: Processing

Once payment is made, the card provider may keep the transaction in **Processing** status for up to **30 days**. This is standard banking procedure.

- No action is required during this 30-day window.
- If the status remains unchanged after **31 days**, contact support.

## Card Issuance Timing

- Standard card issuance: up to **30 minutes**.
- In some cases, up to **24 hours** due to network or verification delays.

## Missing Email Verification Code

If you are not receiving the code to issue your card:

1. Check your **Spam/Junk** folder.
2. If not found, try using a **different email address**.
