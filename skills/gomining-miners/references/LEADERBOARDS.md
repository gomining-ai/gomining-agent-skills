# Leaderboards

Public rankings in the GoMining web app. Reached from the top-nav **"..."** menu → **Leaderboards**. The screen has four tabs. Rankings are public; the specific entries change constantly, so only the structure is documented here.

| Tab | Ranks | Columns shown |
|-----|-------|---------------|
| **Miner rewards** | Individual miners by daily reward | №, Miner, Holder, Computing power, Energy efficiency, Daily reward |
| **Miner uniqueness** | Miners by rarity/achievements | №, Miner, Holder, Rarity rating, Achievement rating, Achievements, Uniqueness |
| **Farms** | Whole farms (all of a holder's miners) | №, Holder, Level, Miners, Computing power, Energy efficiency, Daily reward |
| **Liquidity** | Liquidity providers | №, Provider, Liquidity, Positions, Fees received, Coefficient, LP score, GoMining rewards |

The top three in each ranking are shown as podium cards above the table.

## Farm Level (on the Farms leaderboard)

On the **Farms** tab, each farm has a **Level** — this is a **farm-size progression tier**, shown as a small **numeric badge** plus a **named tier**. The named tiers scale up with the farm's size (its total computing power / number of miners), e.g. a small farm shows **"Miner S"** while large farms show **"Data center M"**, **"Data center L"**, and so on — bigger farm → higher level.

Important — **this is NOT the Miner Wars League system.** Do not answer a question about the **farm Level / rank on the leaderboard** by pointing to Miner Wars Leagues (Odyssey / Eclipse / Horizon / Dune) — they are different things:
- **Farm Level** = a farm-size tier shown on **Leaderboards → Farms** (e.g. "Level 4", "Data center L").
- **Miner Wars League** = your Clan's competitive tier inside Miner Wars.

The exact level thresholds and the full ordered list of tier names are **not documented here**. So explain what the Level is and where to see it (the **Farms** leaderboard), but do **not** invent the complete list of levels or their precise cut-offs — if the user needs the full breakdown, point them to the Farms leaderboard in-app (or to GoMining support). Don't quote a specific holder's level/power from memory.

## Liquidity Pools program — winding down

The **Liquidity** leaderboard shows a notice that the Liquidity Pools program is ending: final rewards are paid to all eligible participants by **May 20, 2026**, and the leaderboard remains available with final standings until **early June 2026**. If a user asks whether the liquidity/LP-rewards program is still running, this is the documented status.
