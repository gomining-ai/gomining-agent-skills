# Mining Farm Screen Layout

What a user sees on the **My miners → Mining farm** screen in the GoMining web app. Use this to tell users where a control or metric lives. Account-specific values (miner count, hashrate, percentages) are not listed here — only the fixed layout.

## My Miners Sub-Tabs

The My miners section has these tabs across the top:

| Tab | Purpose |
|-----|---------|
| **Mining farm** | Overview of the farm and the list of owned miners |
| **Dashboard** | Mining statistics and performance |
| **Rewards** | View and withdraw rewards |
| **Selling** | List a miner for sale |

A **Watch live mining** link is shown above the farm panel.

## Mining Farm Panel

The Mining farm panel shows farm-level metrics as tiles and two controls:

| Element | What it is |
|---------|------------|
| **Miners** | Total number of miners owned |
| **Power** | Total hashrate of the farm, in TH |
| **Efficiency** | Average energy efficiency, in W/TH |
| **Discount** | Active discount, shown as a percentage |
| **Service** button | Opens miner servicing / maintenance |
| **Settings** button | Opens farm settings |

## Miners List

Below the panel, the **Miners** list shows the owned miners as cards. The list can be viewed/sorted with these tabs:

| Tab | Sorts/groups by |
|-----|-----------------|
| **Collections** | Grouped by collection |
| **Energy efficiency** | By W/TH efficiency |
| **Power** | By hashrate (TH) |

## Mobile App Layout

In the mobile app the section is titled **My miners** and has **three** tabs — **Farm**, **Dashboard**, **Rewards** (there is no separate Selling tab; listings live under Marketplace → My listings). A history/clock icon sits in the top-right of the Farm tab.

**Farm tab.** A metrics strip shows **Power** (TH), **Efficiency** (W/TH) and **Discount** (%). Below it are four round action buttons: **Service**, **Upgrade**, **Create miner**, **Settings**. Then a rotating promo banner, and the **Miners** list with a count and three icon controls (filter, refresh, download). Each miner card shows its TH and W/TH badges, its number (e.g. #189) and its name.

**Upgrade flow.** The **Upgrade** button opens an **Upgrade miner** sheet: a miner selector with a **New miner** option, a **One-time / Monthly** toggle, an **Upgrade: Power / Efficiency** switch, a list of upgrade steps (each showing the TH gain, the added BTC/day, the price and an ROI percentage), then **Total**, an asset selector, and **Continue**.

**Dashboard tab.** Tiles for **Total rewards**, **Miners** (with a Create miner link), **Power** and **Mean efficiency** (each with an Upgrade link), followed by a **Rewards** chart with a **Mining mode** selector and a date-range picker. A gear icon opens settings and a share icon is next to it.

**Rewards tab.** A **Mining / Miner Wars** toggle, a gear icon for settings, and a **Rewards for the period** block with a **Choose currency** dropdown, a date-range picker and an export button, above a table of Date / Computing power / Reward rows. A banner at the top ("Receive your daily rewards in GOMINING tokens") links to **Settings**.
